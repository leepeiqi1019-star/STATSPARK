TOPIC 01

Data Description

Data description involves organising, summarising and interpreting data using statistical measures.

1. Measures of Central Tendency

Mean: The average value of a dataset.

Mean = Sum of all observations / Number of observations

Median: The middle value after arranging the data in ascending or descending order.

Mode: The value that occurs most frequently.

Remember This!

  • Mean is affected by extreme values.
  • Median is useful when the dataset contains outliers.
  • Mode can be used for both numerical and categorical data.

Exam Tip: Always arrange the data in ascending order before finding the median.

2. Measures of Dispersion

Range: Difference between the maximum and minimum values.

Range = Maximum value - Minimum value

Variance: Measures how spread out the observations are from the mean.

Standard Deviation: The square root of the variance.

Worked Example

Given the dataset:

2, 4, 6, 8, 10

Step 1: Calculate the Mean

Mean = (2 + 4 + 6 + 8 + 10) / 5

Answer: 6

Step 2: Find the Median

The middle value is 6.

Answer: 6

Step 3: Find the Range

Range = 10 - 2

Answer: 8

TOPIC 02

Probability

Probability measures the likelihood of an event occurring. Its value ranges from 0 to 1.

Basic Probability Formula

P(A) = Number of favourable outcomes / Total number of equally likely outcomes

Important Concepts

Complementary Event: The event that A does not occur.

P(A') = 1 - P(A)

Addition Rule: Used to calculate the probability that at least one of two events occurs.

P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

Multiplication Rule: Used to calculate the probability of two events occurring together.

P(A ∩ B) = P(A) × P(B|A)

Remember This!

  • Probability values are always between 0 and 1.
  • An impossible event has a probability of 0.
  • A certain event has a probability of 1.
  • The sum of probabilities of all possible outcomes is 1.

Exam Tip: Read the question carefully to identify whether it involves an addition rule, multiplication rule or complementary event.

Worked Example

A fair coin is tossed once. Find the probability of getting a head.

Step 1: Identify the outcomes.

Head and Tail.

Step 2: Identify favourable outcomes.

There is only one favourable outcome: Head.

Step 3: Apply the formula.

P(Head) = 1 / 2

Answer: 0.5

TOPIC 03

Random Variables

A random variable assigns a numerical value to each possible outcome of a random experiment.

Expected Value

E(X) = Σ xP(X = x)

Expected value represents the long-run average outcome of a random variable.

Variance

Var(X) = E(X²) - [E(X)]²

Worked Example

Question

A discrete random variable X has the following probability distribution:

x 1 2 3
P(X = x) 0.2 0.5 0.3

Calculate:

  1. The expected value, E(X).
  2. The variance, Var(X).

Step-by-Step Solution

Step 1: Calculate E(X)

E(X) = Σ xP(X = x)
= (1)(0.2) + (2)(0.5) + (3)(0.3)
= 0.2 + 1.0 + 0.9
= 2.1

Step 2: Calculate E(X²)

E(X²) = Σ x²P(X = x)
= (1²)(0.2) + (2²)(0.5) + (3²)(0.3)
= 0.2 + 2.0 + 2.7
= 4.9

Step 3: Calculate Variance

Var(X) = E(X²) - [E(X)]²
= 4.9 - (2.1)²
= 4.9 - 4.41
= 0.49

Final Answer

Expected Value: 2.1

Variance: 0.49

Remember This!

  • A random variable assigns numerical values to outcomes.
  • Expected value represents the long-run average.
  • Variance measures how spread out the values are around the expected value.
  • A larger variance indicates greater variability.

Exam Tip: Remember that variance is expressed in squared units, while standard deviation is expressed in the original units.

TOPIC 04

Probability Distributions

Probability distributions describe how probabilities are assigned to possible values of a random variable.

Binomial Distribution

Used when there are a fixed number of independent trials, each with two possible outcomes and a constant probability of success.

P(X = x) = C(n,x) p^x (1-p)^(n-x)

Worked Example

Question

A student has a probability of 0.4 of answering a multiple-choice question correctly. The student answers 5 independent questions.

Let X represent the number of questions answered correctly.

Calculate the probability that the student answers exactly 2 questions correctly.

Step-by-Step Solution

Step 1: Identify the values

n = 5
p = 0.4
x = 2

Step 2: Apply the Binomial Formula

P(X = x) = C(n,x) p^x (1-p)^(n-x)
P(X = 2) = C(5,2)(0.4)²(0.6)³

Step 3: Calculate

= 10 × 0.16 × 0.216
= 0.3456

Final Answer

The probability that the student answers exactly 2 questions correctly is:

P(X = 2) = 0.3456

Poisson Distribution

Used to model the number of occurrences in a fixed interval under suitable assumptions.

P(X = x) = (e^-λ × λ^x) / x!

Normal Distribution

A continuous probability distribution with a symmetric, bell-shaped curve.

Remember This!

  • Binomial distribution involves a fixed number of independent trials.
  • Each binomial trial has two possible outcomes: success or failure.
  • Poisson distribution models the number of occurrences in a fixed interval.
  • Normal distribution is symmetric and bell-shaped.
  • In a normal distribution, the mean, median and mode are equal.

Exam Tip: Identify the characteristics of the question before deciding which probability distribution to use.

TOPIC 05

Correlation & Regression

Correlation measures the strength and direction of the relationship between two variables.

Correlation Coefficient

The correlation coefficient, r, ranges from -1 to +1.

  • r = +1: Perfect positive correlation
  • r = -1: Perfect negative correlation
  • r = 0: No linear correlation

Linear Regression

y = a + bx

Worked Example

Question

The correlation coefficient between the number of hours studied (X) and examination marks (Y) is 0.85.

Answer the following questions:

  1. Interpret the correlation coefficient.
  2. Given the regression equation Y = 30 + 8X, estimate the examination mark when a student studies for 5 hours.

Step-by-Step Solution

Step 1: Interpret the correlation coefficient

Since r = 0.85 is positive and close to +1, there is a strong positive linear correlation between study hours and examination marks.

Step 2: Identify the regression equation

Y = 30 + 8X

Given that X = 5 hours, substitute X = 5 into the regression equation.

Step 3: Calculate the predicted mark

Y = 30 + 8(5)
Y = 30 + 40
Y = 70

Final Answer

Correlation: Strong positive linear correlation.

Predicted examination mark: 70 marks.

A regression equation can be used to describe a linear relationship and make predictions within an appropriate context.

Remember This!

  • Correlation describes the strength and direction of a linear relationship.
  • A positive correlation means both variables tend to increase together.
  • A negative correlation means one variable tends to decrease as the other increases.
  • Correlation does not necessarily mean causation.
  • Regression can be used to estimate or predict values.

Exam Tip: Pay attention to the sign and magnitude of the correlation coefficient when interpreting r.
